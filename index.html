Avant de jouer

  • Sur ordinateur, avec Chrome, Edge ou Firefox récent. Un casque, c'est mieux.
  • Le premier chargement prend un moment (environ 50 Mo), les suivants sont rapides.
  • Cliquez dans le jeu pour prendre la souris, Échap pour la libérer.
